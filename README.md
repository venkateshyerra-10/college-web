# 🏫 MIT - Maya Institute of Technology

A multi-page college website created using HTML5 as part of my Full Stack Development learning journey.

## 📌 Project Overview

This project is a basic college website designed to provide information about the college, its departments, achievements, admission process, and contact details.

The main goal of this project is to practice HTML5 concepts and build a structured, multi-page website.

## 🚀 Pages

- 🏠 Home
- ℹ️ About
- 🏢 Departments
- 🏆 Achievements
- 📝 Admissions
- 📞 Contact

## 🛠️ Technologies Used

- HTML5
- Basic Internal CSS

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Use the navigation bar to explore the different pages.
